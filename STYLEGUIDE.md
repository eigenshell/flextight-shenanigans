# Style Guide


## Naming Conventions
* All identifiers must use snake_case. camelCase is not allowed. *
* Use descriptive variable names. *


## Function Naming
* All functions must follow the [verb]_[subject] pattern. *
* Examples: *

** read_users **
** write_users **
** get_users **
** put_users **


## Function Arguments
* Arguments must be named and have meaningful names. *
* Arguments with default values should be last in the argument list. *

## Comments
* Comments should be used to explain why the code is doing something. *
* Code itself should be self explanatory and ideally not need comments. *
